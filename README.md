# HirePulse Frontend

Modern single-page application built with React, TypeScript, Vite, and Tailwind CSS.

## Features
- Modular feature-based directory architecture
- TanStack React Query v5 for server state & caching
- React Router v6 with `ProtectedRoute` and `RoleRoute` guards
- Axios with request token attachment & 401 automatic JWT token refresh
- React Hook Form + Zod schema validation
- Live WebSocket notifications with bell counter
- Recharts visualizations on the Administrator and Recruiter dashboards

## Running Locally
```bash
npm install
npm run dev
```
Runs at `http://localhost:5173`.
